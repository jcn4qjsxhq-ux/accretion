# Data

This public repository includes one small demo file:

```text
data/demo_data.txt
```

It is a 2025 slice of the development photometry table and is included so users
can run the quickstart without providing their own observations.

Put your own files here locally:

```text
data/raw/
data/processed/
```

The expected columns are documented in [../docs/data_format.md](../docs/data_format.md).
The `raw/` and `processed/` folders are ignored by Git so uploaded/public
repositories do not include private observational data by accident.
